# Files for the OSF registration

1. Create an OSF account (osf.io) and a new project, e.g. "Carbon traps in carbon-aware workflow scheduling".
2. Registrations -> New registration -> template "OSF Preregistration" (or "Open-Ended Registration").
3. Paste or attach `WINTER_REPLICATION_PREREG.md`. Attach `CONFIRM_PREREG.md` (the sealed confirmatory plan) and
   `hashes.txt`. Enter the repository URL and the commit hash listed in `hashes.txt`.
4. Make the registration public immediately (no embargo) so its date is visible.
5. Send the registration DOI; it goes into Section 5.3 of the manuscript.
